One original fortune-cookie line for a software developer, written by a small deterministic program for make.fun's "Fortune Cookie Wisdom for Developers" bounty:

> The estimate you gave in the meeting was a wish; the code heard it as a promise.

## Run it

```sh
node main.ts
```

The program writes the line (80 characters, no trailing newline) to `entry.txt` inside the output directory named by `MAKEFUN_OUTPUT_DIR` (or a local `output/` folder when that variable is absent). It uses only the Node standard library, with no network, no randomness, and no clock, so every run produces byte-identical output.
